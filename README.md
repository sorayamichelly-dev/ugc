# Soraya Oliveira — UGC

Site pessoal de criadora de conteúdo UGC.

- `index.html` — página de links (vai na bio do Instagram, TikTok e YouTube)
- `portfolio/` — portfólio com os vídeos, nichos, processo e pacotes
- `midia-kit/` — mídia kit com os números do Instagram, para enviar a marcas

Cada uma dessas duas pastas tem um `build-pdf.py`, que gera a versão em PDF a
partir do próprio `index.html` (as fontes vão embutidas, senão o arquivo perde
os acentos). Depois de editar a página, rode o script da pasta e publique o PDF
junto.

Publicado com GitHub Pages.
